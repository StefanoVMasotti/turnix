# Contexto del Proyecto

Nombre: Turnix

Turnix es una plataforma SaaS para la gestión de turnos.

Tecnologías:

Frontend:

- React
- Vite
- TypeScript
- Tailwind

Backend:

- NestJS
- PostgreSQL
- Supabase

Arquitectura:

Frontend
↓
REST API
↓
NestJS
↓
PostgreSQL

El proyecto está completamente documentado dentro de la carpeta docs/.

Antes de implementar cualquier funcionalidad, revisar:

- architecture/
- database/
- ui-ux/
- decisions/

El objetivo es seguir exactamente la arquitectura definida.
