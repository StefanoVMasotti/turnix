# Design System

## Introducción

El Design System de Turnix define la identidad visual de la aplicación y establece las reglas que deberán seguir todos los componentes del sistema.

El objetivo es garantizar una experiencia consistente, moderna y profesional en todas las pantallas.

---

# Filosofía

Turnix busca transmitir una imagen:

- Moderna
- Profesional
- Minimalista
- Elegante
- Tecnológica

La interfaz debe sentirse rápida, limpia y fácil de utilizar.

---

# Estilo Visual

Se utilizará una interfaz oscura (Dark Theme) como diseño principal.

Se evitarán colores saturados y fondos blancos.

El diseño estará inspirado en productos como:

- Vercel
- Stripe
- Linear
- Clerk
- Raycast
- Notion

# Inputs

Todos los campos deberán mantener la misma apariencia.

Estados:

- Normal
- Focus
- Error
- Disabled

---

# Cards

Las cards serán uno de los componentes principales del sistema.

Todas deberán compartir:

- mismo radio
- mismo padding
- mismo borde
- mismo estilo de título
- mismo estilo de botones

---

# Badges

Estados:

- Confirmado (verde)
- Pendiente (amarillo)
- Cancelado (rojo)
- Nuevo (azul)

---

# Iconografía

Se utilizará Lucide React.

Todos los iconos deberán mantener el mismo tamaño dentro de cada contexto.

---

# Responsive

Desktop

Tablet

Mobile

Todos los componentes deberán adaptarse sin cambiar su funcionamiento.

---

# Accesibilidad

Se priorizará:

- Alto contraste
- Tamaños adecuados
- Navegación clara
- Botones grandes
- Estados visuales bien definidos
