# Objetivo

El archivo de Figma representa el flujo completo de reserva de turnos para la primera versión (MVP) de Turnix.

El objetivo principal es validar la experiencia del usuario y definir la estructura de las pantallas antes de comenzar el desarrollo.

---

# Flujo diseñado

- Landing
- Selección de servicio
- Selección de profesional
- Selección de fecha y horario
- Confirmación del turno

También incluye los primeros bocetos del Panel de Administración.

# Decisiones de diseño

## Objetivo

La interfaz debe transmitir una imagen moderna, elegante y profesional.

Se busca una experiencia simple y rápida para que un cliente pueda reservar un turno en menos de un minuto.

---

## Paleta de colores

La paleta utilizada actualmente en Figma es únicamente temporal.

Los colores verdes utilizados fueron empleados para acelerar el diseño del flujo y **no representan la identidad visual final del proyecto**.

La versión final utilizará una paleta basada en tonos:

- oscuros
- fríos
- neutros

Inspirada en aplicaciones modernas SaaS.

Como referencia visual:

- fondos gris grafito
- grises oscuros
- azul petróleo
- azul acero
- detalles en blanco
- un único color de acento para acciones principales

---

## Filosofía

El diseño prioriza:

- simplicidad
- legibilidad
- accesibilidad
- pocos clics
- componentes reutilizables
- consistencia visual

---

# Instrucciones para desarrollo

Durante la implementación:

- utilizar el flujo definido en Figma
- respetar el orden de navegación
- no modificar el flujo sin actualizar la documentación
- priorizar componentes reutilizables
- evitar lógica de negocio en componentes de presentación

Las decisiones de arquitectura tienen prioridad sobre el diseño visual.
